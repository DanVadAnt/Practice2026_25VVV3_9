# Практика

Репозиторий бригады 9 (группа 25ВВВ3) по учебной практике 1 курса. Вариант: **поразрядная сортировка**.

## Описание задания

В рамках практики необходимо:

Разработать программу на языке C, реализующую алгоритм сортировки из варианта, с описанием разработки и тестирования.

Программа реализует ввод данных через `scanf`, арифметические операции, ветвление (`if / else`) и работу с файлами (создание/открытие, чтение, запись, закрытие).

## Алгоритм: поразрядная сортировка

Поразрядная сортировка (radix sort) — это алгоритм, который сортирует числа по отдельным разрядам (цифрам). В зависимости от порядка обработки разрядов различают:

- **LSD (least significant digit)** — сортировка начинается с младшего разряда и заканчивается старшим;
- **MSD (most significant digit)** — сортировка начинается со старшего разряда к младшему.

Обычно используется устойчивая сортировка подсчётом (counting sort) для каждого разряда. Основные шаги алгоритма (для LSD):

1. Определить максимальное количество разрядов в сортируемых числах (например, максимальное число разрядов в самом большом числе).
2. Для каждого разряда (от младшего к старшему):
   - распределить элементы по корзинам (10 корзин для десятичной системы) в соответствии со значением текущего разряда;
   - собрать элементы обратно в массив в порядке корзин (сохраняя устойчивость).
3. Повторять шаг 2 для всех разрядов.
4. После обработки старшего разряда массив будет полностью отсортирован.

Алгоритм работает за O(d·n), где d — количество разрядов, n — количество элементов. Он эффективен для целых чисел и строк фиксированной длины.
