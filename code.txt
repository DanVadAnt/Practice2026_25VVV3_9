// 1. ВСПОМОГАТЕЛЬНАЯ ФУНКЦИЯ: СОРТИРОВКА ПОДСЧЁТОМ ПО РАЗРЯДУ
// ============================================================
void countingSortByDigit(vector<int>& arr, int exp) {
    int n = arr.size();
    if (n <= 1) return;

    vector<int> output(n, 0);
    int count[10] = { 0 };

    // Подсчёт количества чисел с каждой цифрой в текущем разряде
    for (int i = 0; i < n; i++) {
        int digit = (arr[i] / exp) % 10;
        count[digit]++;
    }

    // Преобразование count для определения позиций
    for (int i = 1; i < 10; i++) {
        count[i] += count[i - 1];
    }

    // Построение выходного массива (устойчивая сортировка)
    for (int i = n - 1; i >= 0; i--) {
        int digit = (arr[i] / exp) % 10;
        output[count[digit] - 1] = arr[i];
        count[digit]--;
    }

    // Копирование отсортированного массива обратно
    for (int i = 0; i < n; i++) {
        arr[i] = output[i];
    }
}

// ============================================================
// 2. ОСНОВНАЯ ФУНКЦИЯ: ПОРАЗРЯДНАЯ СОРТИРОВКА (LSD)
// ============================================================
void radixSort(vector<int>& arr) {
    if (arr.size() <= 1) return;

    // Нахождение максимального элемента
    int maxVal = arr[0];
    for (int i = 1; i < arr.size(); i++) {
        if (arr[i] > maxVal) maxVal = arr[i];
    }

    // Сортировка по каждому разряду
    for (int exp = 1; maxVal / exp > 0; exp *= 10) {
        countingSortByDigit(arr, exp);
    }
}

// ============================================================
// 3. ФУНКЦИЯ ЗАПИСИ МАССИВА В ФАЙЛ
// ============================================================
void writeArrayToFile(const vector<int>& arr, const string& filename, const string& header) {
    ofstream outFile(filename.c_str());
    if (outFile.is_open()) {
        outFile << header << endl << endl;
        outFile << "Количество элементов: " << arr.size() << endl << endl;

        for (int i = 0; i < arr.size(); i++) {
            outFile << setw(8) << arr[i];
            if ((i + 1) % 10 == 0) outFile << endl;
        }
        outFile.close();
        cout << "✅ Данные записаны в файл: " << filename << endl;
    }
    else {
        cout << "❌ Ошибка открытия файла: " << filename << endl;
    }
}

// ============================================================
// 4. ФУНКЦИЯ ГЕНЕРАЦИИ МАССИВА
// ============================================================
void generateArray(vector<int>& arr, int size, int minVal, int maxVal, int type) {
    arr.resize(size);

    switch (type) {
    case 1: // Случайные данные
        for (int i = 0; i < size; i++) {
            arr[i] = minVal + rand() % (maxVal - minVal + 1);
        }
        break;

    case 2: // Упорядоченные (по возрастанию)
        for (int i = 0; i < size; i++) {
            arr[i] = minVal + i * ((maxVal - minVal) / size);
        }
        break;

    case 3: // Инвертированные (по убыванию)
        for (int i = 0; i < size; i++) {
            arr[i] = maxVal - i * ((maxVal - minVal) / size);
        }
        break;

    case 4: // Повторяющиеся элементы
        for (int i = 0; i < size; i++) {
            arr[i] = minVal + (i % 10) * ((maxVal - minVal) / 10);
        }
        break;

    default:
        for (int i = 0; i < size; i++) {
            arr[i] = minVal + rand() % (maxVal - minVal + 1);
        }
    }
}

// ============================================================
// 5. ФУНКЦИЯ ПРОВЕРКИ СОРТИРОВКИ (для тестирования)
// ============================================================
bool isSorted(const vector<int>& arr) {
    for (int i = 1; i < arr.size(); i++) {
        if (arr[i] < arr[i - 1]) return false;
    }
    return true;
}
